# 해양사업부 인력현황 대시보드

CSV 명부 파일을 업로드하면 해양사업부 인원 현황을 자동으로 집계하여 보여주는 단일 HTML 파일 대시보드입니다. 별도 서버나 빌드 과정 없이 브라우저에서 파일을 열기만 하면 동작합니다.

## 개요

- 당월 명부 CSV 한 개만 올리면 부서별/직군별/학력별/파견/근속연수 현황이 즉시 계산됩니다.
- 전월 명부 CSV를 추가로 올리면 전월 대비 인력증감(채용, 전입, 전출, 퇴직, 휴직, 복직)과 발령 변동사항(전배, 직급변동, 근무지이동 등)이 함께 표시됩니다.
- 모든 계산은 브라우저 내 자바스크립트에서 이루어지며, 업로드한 CSV는 외부로 전송되지 않습니다.

## 주요 기능

| 영역 | 내용 |
|---|---|
| KPI 카드 | 총원, 전월 대비 변동 건수, 파견 인원, 평균 근속연수 |
| 인력증감 Flow | 채용/전입/복직/퇴직/전출/휴직 인원 흐름 (전월·당월 비교 시) |
| 발령 변동사항 | 인원별 전배, 직급변동, 근무지·사업장 이동, 파견시작 내역 |
| 부서별 인원현황 | 직속조직 / 해양연구소 / SV사업센터 그룹별 인원 |
| 직군별 인원현황 | R(연구개발)/S(영업)/A(경영지원)/계약직 직군 분포 |
| 학력별 현황 | 조직별 박사/석사/학사 인원 표 |
| 파견 인원현황 | 파견지역별 인원 분포 |
| 근속연수 현황 | 근속 구간별 인원, 팀별 평균 근속연수 |
| 색상 테마 | navy/teal/violet/warm 프리셋 및 커스텀 HEX 컬러 지정 |

## 필요한 CSV 컬럼

명부 CSV는 다음 컬럼명을 포함해야 정상적으로 집계됩니다.

- 사번, 성명, 재직상태
- 원소속부서, 원소속사업장, 원소속근무지역
- 직위코드명, 직급명, 직급코드
- 입사일, 그룹입사일
- 최종학력
- 파견조직코드명, 파견지역

컬럼명이 다르면 해당 항목이 인식되지 않으므로, 사내 명부 시스템에서 내보낼 때 위 컬럼명을 그대로 유지하는 것을 권장합니다.

## 사용 방법

1. `해양사업부_인력현황_대시보드_동적.html` 파일을 더블클릭하여 브라우저로 엽니다.
2. 상단 데이터 업로드 영역에서 당월 명부 CSV를 올립니다. (필수)
3. 전월 대비 변동 현황까지 보려면 전월 명부 CSV를 추가로 올립니다. (선택)
4. 기준일이 필요하면 상단의 기준일 입력란에서 조정합니다. 근속연수 계산과 채용/전입 구분 기준으로 사용됩니다.
5. 필요 시 테마 패널에서 색상을 변경합니다.

## 코드 구조

파일 하나에 스타일, 마크업, 로직이 모두 포함되어 있으며, 스크립트는 아래 순서로 구성되어 있습니다.

1. 설정값 — 조직 구조 및 직군 분류 기준 (`ORG_GROUPS`, `MARINE_TEAMS`, `EXEC_TITLES`, `jobFamily`)
2. 색상 테마 처리 (`setTheme`, `setCustom`, `themeColors`)
3. CSV 파싱 및 파일 업로드 처리 (`parseCsvText`, `onRosterFile`)
4. 공용 렌더 헬퍼 — 막대 리스트, 도넛 차트, 테이블 (`renderBarList`, `renderDonut`)
5. 각 카드 렌더 함수 (`renderDeptCard`, `renderJobCard`, `renderEduCard`, `renderDispatchCard`, `renderTenureCards`)
6. 전월/당월 비교 로직 (`renderComparison`, `renderFlowCard`, `renderChangeTable`)
7. 초기화 (`init`)

### 조직 개편 시 수정 위치

회사 조직이 개편되어 팀 이름이 바뀌거나 팀이 추가·이동되는 경우, 실제 인원 데이터를 손댈 필요 없이 파일 상단의 아래 상수만 수정하면 됩니다.

- `ORG_GROUPS` : 상위 그룹(직속조직/SV사업센터) 소속 팀 목록
- `MARINE_TEAMS` : 해양사업부로 집계할 전체 팀 목록 (전사명부 업로드 시 이 목록으로 필터링)
- `DEPT_ORDER`, `GROUP_ORDER` : 부서별 인원현황 카드의 표시 순서
- `EXEC_TITLES` : 근속연수 집계에서 제외할 임원 직위 목록

## 알려진 제한사항

- `classifyLeaver` 함수는 현재 모든 퇴직을 일괄적으로 '퇴직'으로 분류합니다. 원본 명부에 이직처나 퇴사사유 컬럼이 있다면 이 함수에 조건을 추가하여 퇴직/전출을 구분할 수 있습니다.
- 신규채용과 전입 구분은 입사일의 연월이 기준일과 일치하는지로 판단하므로, 입사일 컬럼 형식이 예상과 다르면 오분류될 수 있습니다.
- CSV 파싱기는 콤마 구분 및 큰따옴표 이스케이프만 지원하며, 별도 라이브러리 없이 직접 구현되어 있습니다.
